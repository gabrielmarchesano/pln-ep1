# Research results

This directory contains the historical dataset audits and interventions, lexical classifiers, semantic models, and BERTimbau runs. They are preserved for comparison and future research; none is the selected delivery adapter. The frozen development/holdout split is [`dataset-hypotheses-20260923/splits.csv`](dataset-hypotheses-20260923/splits.csv).

See the [research documentation](../../docs/research/README.md). Historical `results/<run-name>` paths inside immutable manifests are resolved by input readers; no filesystem aliases are present.
